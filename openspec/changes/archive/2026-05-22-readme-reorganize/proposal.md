## Why

LocateRoom 项目需要一份完整的 README.md 来展示项目成果。需求文档明确要求 README 包含架构与取舍说明、性能实测数据和 AI 协作说明（工具、任务拆解、推翻的 AI 方案及原因），但当前项目根目录没有 README.md 文件，需要从零组织。

## What Changes

- 新增项目根目录 `README.md`，替代原有的 `LocateRoom.md` 项目需求文档
- README 包含三大核心板块：架构与取舍、性能实测、AI 协作说明
- 从 `知识扩展.md` 和 `存疑.md` 中提取架构决策历程和 AI 协作记录
